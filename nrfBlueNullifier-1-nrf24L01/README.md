# nrfBlueNullifier-1-nrf24L01

Herramienta que interfiere señales de Bluetooth Clásico usando 1 módulo nrf24L01.

# Tipos de código

Hay `2` tipos de código, según el cableado del módulo nrf24L01:

1. HSPI
2. VSPI
